## Acheter des Coins

<figure><img src="https://1103532016-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FHAeWF9C5i1BoFU7up2Dj%2Fuploads%2FrIFNekde7vxJE269RX9E%2Fimage.png?alt=media&#x26;token=75a62911-48ae-4f1b-a6cb-89ff45d1a433" alt=""><figcaption></figcaption></figure>

1. Pour commencer, cliquez sur le bouton **COINS**.
2. Choisissez un montant, puis cliquez sur **ACHETER**, un pop up apparaît sur votre page.
3. Cliquez sur **AJOUTER AU PANIER**.
4. Connectez-vous à votre compte FiveM via le bouton **LOGIN WITH FIVEM**.
5. Vous arriverez ensuite sur le site de FiveM, cliquez alors sur **CONTINUE** si votre compte FiveM est déjà connecté, sinon connectez-le.
6. Après avoir cliqué sur **CONTINUE**, vous allez retombé sur le site de la boutique. Vous devrez noter votre code boutique ou celui de votre ami.
7. **Vous pouvez retrouver votre code boutique via le menu F1 comme ci-dessous :**&#x20;
8. Une fois votre code boutique noté, cliquez sur **CONTINUE**.
9. Vous arriverez ensuite sur cette page pour **confirmer votre achat** avant de payer.
10. Vérifiez bien **votre code boutique noté** pour éviter tout soucis à la suite de votre achat.
11. Remplissez **le formulaire** suivant :
12. Choisissez **votre mode de paiement**.
13. Renseignez **vos informations** par rapport au mode de paiement.
14. Puis **confirmer votre paiement**.

{% hint style="warning" %}
**Une fois le paiement effectué**, un délai maximum de **15 minutes** est nécessaire pour recevoir vos **tokens en jeu**.

Si vous n’avez **pas reçu vos tokens** après ce délai, merci de :

1. Créer un **ticket sur Discord**.
2. Joindre la **facture** reçue par mail.
3. Ajouter une **photo de votre code boutique**.
   {% endhint %}
