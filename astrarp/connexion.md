## Première méthode

* Cliquez sur <mark style="color:red;">**Jouer**</mark>
* Ensuite, rechercher <mark style="color:red;">**ASTRA**</mark> dans la liste des serveurs FiveM.
* Puis cliquez sur <mark style="color:red;">**ASTRA**</mark> , enfin vous pouvez vous connecter.

## Deuxième méthode

* Appuyez sur <mark style="color:red;">**F8**</mark> dans le menu FiveM, puis collez ceci dans la console -> \
  **connect** [<mark style="color:red;">**https://play.astrarp.net/**</mark>](https://play.astrarp.net/)**,**
* Appuyez sur <mark style="color:red;">**ENTRER**</mark> et vous voilà en cours de connexion à notre serveur !

{% hint style="warning" %}
Si vous n'arrivez pas à vous connecter, cela peut venir aussi de **FIVEM**, vous pouvez vérifier de vous même si **FIVEM** à un soucis sur ses serveurs via : [**Cfx.Re**](https://status.cfx.re/)
{% endhint %}
